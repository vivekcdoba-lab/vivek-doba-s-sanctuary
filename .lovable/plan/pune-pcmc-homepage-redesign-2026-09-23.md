# Pune & PCMC Homepage Redesign

## Goal
Rebuild only the homepage so it speaks directly to Pune and PCMC business owners, while preserving the current brand colors, site header/footer, and Vivek Doba’s original photo.

## Homepage structure
1. Create an image-led hero with the supplied brand line, single H1, supporting line, two actions, Vivek Doba’s photo, and the approved 840+/since-1998/local trust line.
2. Add “Which one is you?” with three warm, realistic Indian business-owner image cards for Business, Health, and Family.
3. Add a concise illustrated Golden Triangle section with Business, Health, and Family corners and a link to the three-minute score.
4. Show four course cards using the existing dynamic course data and image, outcome, duration, price/GST, and detail links.
5. Add a concise Meet Vivek Doba section using only facts already present on the About page.
6. Add a testimonial-video section that stays hidden until YouTube IDs are supplied.
7. Add the existing Book + Workbook offer with its course image, price, launch note, and pre-book action.
8. Add five accessible FAQ items and matching FAQPage structured data.
9. End with a deep-maroon diagnostic call section and phone action.

## Technical details
- Generate three cohesive, realistic image assets for the Business, Health, and Family mirror cards.
- Use semantic design tokens and existing button/course utilities; no hardcoded component colors.
- Keep exactly one H1, set image dimensions and lazy loading below the fold, and preserve responsive behavior.
- Use the existing course data so public course updates continue to flow into the homepage.
- Verify desktop and mobile rendering, destinations, structured data, console errors, and the single-H1 rule.
